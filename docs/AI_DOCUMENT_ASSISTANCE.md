# Local AI document assistance

Icarus now uses local ONNX transformer models for two advisory tasks:

- semantic similarity ranks a submitted document against the demo document types;
- extractive question answering suggests organization name, certificate/reference number, and explicit validity date, with the original page and model score.

An optional OpenAI Responses API adapter is available for structured extraction from irregular text layouts. It is disabled by default (`APP_AI_PROVIDER=local`). To opt in, configure `APP_AI_PROVIDER=openai`, `APP_LLM_MODEL`, and `OPENAI_API_KEY`. This sends extracted page text (up to 18,000 characters) to the configured OpenAI endpoint; it does not send the original file. The UI and `/api/ai/status` disclose external processing when credentials are present. Set the provider back to `local` to keep document text on-device. No API key or paid service is required for the core demo.

The adapter requests schema-constrained JSON, then independently checks every proposed field's page number, exact supporting quote, and value against the extracted source page. Unsupported or mismatched suggestions are discarded. Schema validity and quote matching do not prove that a field is correct. Compliance checks remain deterministic and are never generated by the LLM. Provider configuration is replaceable through the `FieldExtractor` interface in `app/llm.py`.

Unavailable assistance is not a finding. When the optional models are not installed and no external provider is configured, uploads record the analysis status as `manual_review` but no document finding is raised: the submission is not defective just because this deployment did not run a model. `EXTRACT-001` fires only when text extraction genuinely failed, or when a configured assistance path was attempted and could not produce a usable result (`app.ai.assistance_attempted`).

The classification score is cosine similarity, not a calibrated probability. The extraction score is a model score, not a guarantee of correctness. These general-purpose English models were not fine-tuned or evaluated for real compliance documents. Results are suggestions only: the selected upload category and deterministic demo rules remain unchanged, and an reviewer must check the source document. Do not treat these features as forgery detection or regulatory reasoning. External LLM extraction is not configured or called by default.

## Install and run

The runtime dependencies (`onnxruntime` and `tokenizers`) are included in `requirements.txt` and the Linux runtime lock. On Windows, install model assets once from the pinned public model revisions:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\scripts\download_ai_models.ps1
```

Then start or restart the local app. `APP_AI_ENABLED` defaults to true; set it to `false` to disable inference. If assets or dependencies are missing, uploads still work and the app explicitly marks AI assistance unavailable and leaves the record for manual review. `/api/ai/status` reports whether models are installed and confirms `external_processing: false`.

The model downloads total about 110 MB and are stored in `data/models/icarus-ai`, outside public static storage and excluded from Docker build context. The downloader pins repository revisions and checks SHA-256 hashes for all four files. Inference uses CPU ONNX Runtime on the same machine; application documents are not sent to Hugging Face or another service. Hugging Face is contacted only by the one-time model setup script.

## Model provenance

- Classifier embeddings: [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2), pinned at `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`; the model card lists Apache-2.0.
- Extractive QA: [Xenova/distilbert-base-cased-distilled-squad](https://huggingface.co/Xenova/distilbert-base-cased-distilled-squad), pinned at `bdbb0a5e9c617c3c7ea9f3cbaf2be3ad871bcd7d`; based on the [Apache-2.0 DistilBERT SQuAD model](https://huggingface.co/distilbert/distilbert-base-cased-distilled-squad).

Model quality, bias, extracted values, and page references must be evaluated on a labelled, representative dataset before any wider use. No real organizational or personal documents should be used for this demo.
