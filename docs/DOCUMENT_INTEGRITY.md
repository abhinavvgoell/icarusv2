# Document integrity and replacement history

Uploads are immutable. When an submitter replaces a document, the new record points to the prior document using `supersedes_document_id`; the original file, hash, scan record and extraction result remain preserved. Automated checks consider only the current version of each document, while the full same-type history is available through `/api/documents/{document_id}/versions`.

Scanned PDFs use embedded text first. Pages without embedded text are OCRed with Tesseract when it is installed; mixed PDFs retain their original page indexes, and OCR-derived fields are deliberately low-confidence and require human confirmation. The staging Docker image includes the English Tesseract engine. Local Windows users can install Tesseract 5 with English trained data using the installer linked from the [Tesseract installation guide](https://github.com/tesseract-ocr/tessdoc/blob/main/Installation.md), then restart Arbiter. Set `APP_OCR_LANGUAGE` to an installed Tesseract language code when needed (default: `eng`). If OCR is unavailable or fails, the affected page remains empty and the UI routes it to manual review. Production deployments should run OCR in a sandboxed worker with resource limits and capture the OCR engine version in operational records.

Cryptographic validation of government-issued digital signatures is not implemented because it requires approved trust anchors, revocation validation and the relevant issuing-authority policy.

For a PDF, an authorized case viewer can request an inspection of interactive signature fields. Arbiter reports detected field names, page numbers, and whether a field contains a value. This is a structural review cue only: it does not validate the signature bytes, signer identity, certificate chain, trust anchors or revocation status. If no interactive field is detected, visible signature images, QR codes and external external source records remain unchecked. A human must inspect the source and use an authorized validation method where required.
